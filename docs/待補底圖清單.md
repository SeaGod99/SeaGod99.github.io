## 採集點地圖檢視缺的底圖（type=instance，預設不抓）

| mapId | 名稱 | mapKey | 檔名 | 狀態 |
|------:|------|--------|------|------|
| 584 | 雲冠群島 / The Diadem | a2fx/00 | a2fx_00.jpg | ✅ **已補（2026-07-26）** |

預設與 `--all` 之間的折衷：用 `--id` 單獨補這張，不必多抓上百張副本圖：

```
node scripts/download-maps.mjs --id 584
```

> **2026-07-26 補記——這張圖其實一直都在，壞的是 maps.json 的指向。**
> `assets/maps/a2fx_00.jpg` 早就下載好了，但 `maps.json` 的 584 把 `image.key` 寫成
> **`default/00`**（XIVAPI 的空白羊皮紙佔位圖），於是前端去要不存在的 `default_00.jpg`
> → 404 → fallback 抓遠端，拿到那張沒有地形的空白圖，看起來就像「雲冠群島的地圖消失了」。
> 根因是 `fix-mapkeys.mjs` 以英文地名比對、同名多列取第一個（詳見
> [專案慣例與記憶 §4.7](專案慣例與記憶.md)）。已修腳本並用
> `node scripts/patch-map-default-images.mjs --apply` 補正 584 與 557（完璧王座 → `n4fb/00`）。
> **日後看到任何地圖的 `image.key` 是 `default/00`，先跑這支再懷疑圖沒下載。**
