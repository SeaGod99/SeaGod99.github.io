# 園藝機制對照（配種／土壤／照料／花色）

> 2026-08-12 查證定案。`tools/gardening/` 的「機制速查」分頁與 `scripts/build-gardening.mjs` 的
> `rules` 區塊都以本檔為準；**改任一邊要同步另一邊**。
>
> 這些是**社群知識，不是 datamine 得來的**（遊戲內沒有說明文字，Teamcraft 的 `seeds.json` 也只有
> 配方與時數）。所以出處寫在這裡，日後有爭議直接回查，不要憑印象改。

## 1. 配種

| 事實 | 說明 |
|------|------|
| **判定時機** | **種下的瞬間**就決定，不是收成時。所以要**先把鄰株種好，再種本株**。 |
| **產出物** | **是種子，不是作物。** 本株那格仍然長本株自己的作物，只是收成時額外掉出目標種子——拿到種子後**還要再種一輪**才有目標作物。 |
| **空床不算** | 旁邊是空床就不會配種，所以第一株永遠配不出東西。鄰株只要已經種下即可，**不必成熟**。 |
| **鄰接優先順序** | **右 → 下 → 上 → 左**，取第一個配得起來的鄰居。要配的對象請放在優先順序前面的方向。 |
| **花盆不能配種** | 花盆是單株容器，沒有相鄰格。一定要用園圃。 |
| **園圃規格** | 圓形園圃 4 格（7128）／方形園圃 6 格（7129）／高級園圃 8 格（7130）。交替種下兩種種子時，**N 格一輪能跑 N÷2 組配種**（8 格＝一對種子各 4 株）。 |

### 種植順序（配種在種下的瞬間判定，所以順序才是重點）

1. 先在 **1 號格**種一株不要的作物＋園藝土壤，把整塊田清乾淨。第一株旁邊沒東西，本來就配不出結果。
2. **2 號格之後交替種**本株、鄰株、本株、鄰株……每種下一格就配一次。
3. 最後把 1 號格那株不要的換掉，補上真正要配的那一株。
4. 收成時**一格一格換**，不要整塊清空——空床不會配種，清空了要從頭來一次。

⚠ **各款園圃的實體排列查不到可信來源**（ffxivgardening 的格位圖是圖片檔、wiki 沒寫），
所以頁面上只畫「格子編號 × 交替樣式」，**不畫實體形狀**——畫錯反而會誤導。
配種判定本來就只看鄰接方向的優先序；進遊戲點任一格，對話框會告訴你那是第幾號格。

**這一條是舊版頁面最大的錯**：舊版只印目標作物的 `duration`，等於漏掉「配種拿到的是種子、
還要再種一輪」以及「父本自己也要先配出來」。薩維奈圓蔥實際是 480 小時（20 天），舊版寫 240。

### 成本模型（頁面用的算法）

```
cost(種子) = 0                                          若該種子能直接買／採
           = min over 配方 of
               max(cost(本株種子), cost(鄰株種子)) + 本株作物的培育時數
```

- 「直接可得」**只認 NPC 商店／採集／任務等固定管道，不認市場板**。市場板對每個種子都成立，
  認了它整棵樹會縮成一層，等於沒算。市場板另外標在節點上當捷徑提示。
- **用定點迭代求解，不要用遞迴 memo**：配種關係有環（血椒 ↔ 魔蕨菜那一區），
  遞迴會把環上的 `Infinity` 記進 memo，害整條鏈都變成無解。

## 2. 土壤

| 土壤 | 效果 | 何時用 |
|------|------|--------|
| 薩納蘭土壤 1–3 級（7764–7766） | **提高配種機率** | 配種一律用這個 |
| 黑衣森林土壤 1–3 級（7761–7763） | 提高收穫量（作物與種子） | 只想多收一點時 |
| 拉諾西亞土壤 1–3 級（7758–7760） | 提高 HQ 率 | **6.0 移除採集品 HQ 後已無實質作用** |
| 園藝土壤（16026） | 無任何加成 | 佔位、清田用 |

⚠ 台服官方名是「**薩納蘭**土壤」，不是「沙塵土壤」（那是 Thanalan 的另一種譯法）。

## 3. 照料

- 多數作物 **48 小時**沒照料會枯萎，再 **24 小時**枯死；少數 24 小時就要顧一次 → 一天看兩次最保險。
- 施肥每次減少**剩餘**生長時間的 **1%**，所以越早施越划算。
- 長到可收成之後就**不會再枯死**，可以無限期放著慢慢收。

## 4. 花色（油粕染色）

**花的顏色不是配種、也不是土壤決定的，是施油粕染色。** 這是舊版頁面的第二大缺口：
24 種花每種只收了 1 個顏色（原色），但遊戲裡每種有 9 色、各是獨立道具，共 **216 件**。

| 油粕 | id |
|------|-----|
| 緋紅色油粕 | 14011 |
| 青藍色油粕 | 14012 |
| 金黃色油粕 | 14013 |

**規則**

- 每**現實**小時只能施一次；只對**未成熟**的花有效；**與施放順序無關**。
- 花的**原色在染色過程中視為無色**（例：三色堇原色是紫，施緋紅 ×1 得紅色三色堇）。
- 三色都施完可以再開下一輪染色循環。

| 目標色 | 需施的油粕 |
|--------|-----------|
| 原色 | 不施 |
| 紅 / 藍 / 黃 | 緋紅 / 青藍 / 金黃 各 ×1 |
| 紫 | 緋紅 ＋ 青藍 |
| 橙 | 緋紅 ＋ 金黃 |
| 綠 | 青藍 ＋ 金黃 |
| 白 / 黑 / 混色 | 三色全施，**隨機**開出其中一種，也可能退回原色 |

**原色一律以 datamine 為準，不採社群說法。** `seeds.json` 每個種子對應的產物 id 就是原色：
24 種花裡 22 種原色為紅，**三色堇、大波斯菊為紫，雛菊為黃**。
（英文來源說風信子原色是紫，但資料是 `28948 紅色風信子` → 採資料。）

**第 9 色不一定叫「混色」**：櫻花那一套用的是「**粉色櫻花**」。所以花色清單要用名稱去 `items.json`
反查，不能寫死「混色」，也不能用「種子 id + 1..9」——櫻花樹幼苗(17546) 與花色(17048–17056) 不連號。

## 6. 「這東西拿來幹嘛」的判定

絕大多數作物的用途是**資料算得出來的**，不必手寫：

| 來源 | 欄位 | 說明 |
|------|------|------|
| `recipes.json` | `usedIn` | 被幾個配方吃掉（91 種作物有） |
| `crossBreeds` 反查 | `parentOf` | 它的種子是幾種作物的父本。48 小時那批（塞爾法特爾沙果、瓦爾醋栗…）存在的意義幾乎只有這個 |
| `minions.json` | `minion` | **6 個園藝產物其實是寵物**：洋蔥王子、茄子騎士、蒜頭明星、番茄國王、曼德拉王后、亞拉戈西瓜。其中 4 隻 `gardeningOnly`＝沒有別條路 |
| `obtainable-methods` | `productSources` | 收成物**自己**買不買得到。有的話等於「不必種」 |

**只有兩樣算不出來**，寫在 `build-gardening.mjs` 的 `USE_NOTE`：

| 物品 | 用途 | 出處 |
|------|------|------|
| 薩維奈圓蔥（8166） | 陸行鳥夥伴突破等級上限：rank 10 起每餵 1 顆 +1 級，到 rank 20 共需 10 顆 | [Thavnairian Onion — consolegameswiki](https://ffxiv.consolegameswiki.com/wiki/Thavnairian_Onion)、[Chocobo Companion 指南（Lodestone）](https://na.finalfantasyxiv.com/lodestone/character/31628334/blog/4882104/) |
| 克拉卡蘿蔔（8165） | 餵食陸行鳥夥伴累積經驗值（訓練用） | 同上 |

補完之後「說不出用途」的從 16 種降到 **3 種**（拉札漢檸檬、阿爾基克薰衣草、虛無界風茄）。

⚠ **`productSources` 只能收可重複取得的管道。** 薩維奈圓蔥有一筆 `quest`（任務獎勵），
那是一次性的——拿它當「不必種」會直接騙人，那顆洋蔥你這輩子只拿得到一次。
副本掉落／寶箱這種看運氣的同理排除。加上這條過濾後，「產物可直接取得」由 64 種降為 51 種。

⚠ **社群指南的配方可能過時。** 有指南說薩維奈圓蔥＝克里耶蘿蔔 × 妮美雅百合，但 datamine
（Teamcraft `seeds.json`）的三組配方裡沒有妮美雅百合。**以 datamine 為準**，那是遊戲 sheet 直出的。
