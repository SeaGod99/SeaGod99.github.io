這九本文書屬於 50 級光武的製作流程。（這條資訊由站主提供—— 遊戲的資料表裡查不到武器與書的關聯，所以本站不自稱知道完整階段鏈。）
這頁只涵蓋「填文書」這一段。 前後階段的鏈不在遊戲的資料表裡—— Relic／RelicItem 兩張表是空殼、九本書的 EventItem.Quest 全是 0， 所以「哪把武器要幾本書」「書從哪個 NPC 拿」「下一階段要什麼」查不到依據，一律不寫， 免得憑印象寫錯害人白跑。
三個首領沒有副本連結，因為那三個副本名一般版與高難度版同名， 而資料分不出首領在哪一個（dungeons.json 的 bosses 是空的）。 寧可少一個連結，不要送人去打錯副本。
一般怪只有 30% 查得到座標（monsters.json 就只有這些有 positions）， 其餘只顯示出沒地名，不臆造座標。FATE 的座標齊全。
進度存在這台瀏覽器裡（ffxiv_relic_note），可從首頁「進度備份」匯出。
